# Solaris Endovascular Demo Data Room

Demo status: Synthetic company data for product demonstration only.
Company: Solaris Endovascular, Inc.
Scenario: Series B / strategic investor due diligence for a life-sciences medical technology company.
Prepared for: Solaris AI Due Diligence Agent demo ingestion.
Prepared date: 2026-05-27.

## How to use this pack

Upload this entire folder into the Solaris AI Due Diligence Agent as a private tenant data room. The pack is designed to show:

- data-room ingestion across financial, regulatory, clinical, commercial, IP, and security documents
- auto-drafted due diligence report creation
- claim-level citation back to source documents
- investor Q&A with answer policy controls
- founder dashboard analytics and warm-lead identification

## Demo positioning

The company-specific information in this data room is intentionally synthetic, including management names, revenue, clinical metrics, contracts, and cap table records. Public market and regulatory context uses real-world source references from FDA and CMS to make the demo realistic without representing a real company.

## Suggested demo flow

1. Upload the folder into an isolated Solaris Endovascular tenant.
2. Show ingestion progress across document categories.
3. Generate the DD report and open the cited financial, clinical, and regulatory claims.
4. Log in as an investor and ask: "What are the main regulatory risks before commercialization?"
5. Ask: "What is revenue concentration by customer and how does it affect the 2026 plan?"
6. Ask: "Which claims in the DD summary are based on public sources?"
7. Switch to the founder dashboard and show investor engagement from `08_Investor_QA/investor_activity_export.csv`.

## SharePoint upload

If you use OneDrive sync, copy this folder into the synced SharePoint document library and wait for the sync icon to complete. If using the SharePoint web UI, create a folder named `Solaris_DD_Demo_DataRoom` and upload all subfolders together.
