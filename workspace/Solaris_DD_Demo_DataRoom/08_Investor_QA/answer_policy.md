# Investor Q&A Answer Policy

Document status: Founder only.
Demo status: Synthetic configuration notes.

## Default policy

Mode: Data-bank-only.
Citation requirement: 100% of factual claims must cite a source document.
Unanswered questions: If the data room does not contain support, the agent must say that the answer is not available in the approved data bank.
Sensitive content: Cap table, customer terms, site names, and board minutes require gated investor access.

## Allowed answer modes

Data-bank-only:
Use only approved uploaded documents. Recommended for regulated diligence.

Approved-source whitelist:
Use uploaded documents plus public sources listed in `09_Source_References/references.csv`.

Web fallback:
Disabled for the main investor tenant. May be enabled only in a separate sandbox demo tenant to show entity disambiguation.

## Investor access levels

General investor:
Can view executive summary, company overview, regulatory strategy, clinical evidence summary, IP summary, press releases, security packet, and public source references.

Gated investor:
Can additionally view cap table, board minutes, revenue pipeline, forecast model, customer agreement summary, and pivotal site dataset.

Founder/admin:
Can view answer policy, investor activity export, upload logs, and unpublished report drafts.
